### Project inspired by the Black Hole Games, where you play as a Black hole which consumes everything.  
### In the end, you become the biggest blackhole.

## Description 
- Players start as a small blackhole.
- Players can eat smaller objects to grow larger.
- Players can eat other players if they are smaller than them.
- The game is played in a 2D environment.
- The game is played in real-time.
- The game is played in a web browser.
- The game is played using the mouse.

## Future Features
- Multiplayer game.
- Real-time game.
- Web browser game.
- Mouse game.
